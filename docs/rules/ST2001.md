# ST2001: Validation attribute can't be compared with the contract

**Severity:** Error

The analyzer can only tell whether an implementation's attribute is weaker than its contract's
if it knows what each attribute constrains. It knows the built-in ones; a custom attribute is
code, so until it is described it can only be compared with identical usages of itself. Is
`[AtLeast(0)]` weaker than `[AtLeast(5)]`? Only its author knows. This attribute is declared in
this solution, so its class can be described.

```csharp
public sealed class AtLeastAttribute(int minimum) : ValidationAttribute
{
    public int Minimum => minimum;

    public override bool IsValid(object? value) => value is not int number || number >= minimum;
}

public interface IThermostat { void Set([AtLeast(5)] int degrees); }

public class Thermostat : IThermostat
{
    // error ST2001: Parameter 'degrees' of 'Thermostat.Set(int)': [AtLeast(0)] can't be compared
    // with the attributes of 'IThermostat.Set(int)'. Describe 'AtLeastAttribute' with
    // [ComparableValidation], or repeat the contract's attribute exactly.
    public void Set([AtLeast(0)] int degrees) { }
}
```

## How to fix it

Describe the attribute with `[ComparableValidation]`, so it can be compared with the others on
the same dimension (see [custom validation attributes](../use/custom-attributes.md)):

```csharp
[ComparableValidation(ValidationDimensions.Value, ValidationComparison.LowerBound, Argument = "minimum")]
public sealed class AtLeastAttribute(int minimum) : ValidationAttribute
{
    public int Minimum => minimum;

    public override bool IsValid(object? value) => value is not int number || number >= minimum;
}

public interface IThermostat { void Set([AtLeast(5)] int degrees); }

public class Thermostat : IThermostat
{
    public void Set([AtLeast(0)] int degrees) { }
}
```

Or repeat the contract's attribute exactly:

```csharp
public sealed class AtLeastAttribute(int minimum) : ValidationAttribute
{
    public int Minimum => minimum;

    public override bool IsValid(object? value) => value is not int number || number >= minimum;
}

public interface IThermostat { void Set([AtLeast(5)] int degrees); }

public class Thermostat : IThermostat
{
    public void Set([AtLeast(5)] int degrees) { }
}
```
