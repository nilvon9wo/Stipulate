# ST2002: Validation attribute from outside the solution can't be compared with the contract

**Severity:** Error

As [ST2001](ST2001.md), but the attribute's class comes from outside the solution (a package, say),
so you can't put `[ComparableValidation]` on it.

<!-- reference: Vendor -->
```csharp
namespace Vendor;

public sealed class AtLeastAttribute(int minimum) : ValidationAttribute
{
    public int Minimum => minimum;

    public override bool IsValid(object? value) => value is not int number || number >= minimum;
}
```

```csharp
public interface IThermostat { void Set([Vendor.AtLeast(5)] int degrees); }

public class Thermostat : IThermostat
{
    // error ST2002: Parameter 'degrees' of 'Thermostat.Set(int)': [Vendor.AtLeast(0)] can't be
    // compared with the attributes of 'IThermostat.Set(int)', because 'Vendor.AtLeastAttribute'
    // comes from 'Vendor', outside this solution. Repeat the contract's attribute exactly, or
    // describe it with [assembly: ComparableValidation(typeof(Vendor.AtLeastAttribute), ...)].
    public void Set([Vendor.AtLeast(0)] int degrees) { }
}
```

What counts as the solution is every assembly whose file is under the
`StipulateSolutionRoot` MSBuild property, by default the folder holding
`Directory.Build.props`.

## How to fix it

Describe the class from your own assembly:

```csharp
[assembly: ComparableValidation(
    typeof(Vendor.AtLeastAttribute),
    ValidationDimensions.Value,
    ValidationComparison.LowerBound,
    Argument = "minimum")]

public interface IThermostat { void Set([Vendor.AtLeast(5)] int degrees); }

public class Thermostat : IThermostat
{
    public void Set([Vendor.AtLeast(0)] int degrees) { }
}
```

Or repeat the contract's attribute exactly. See
[describing someone else's attribute](../use/custom-attributes.md#describing-someone-elses-attribute).
