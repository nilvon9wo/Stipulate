# ST3001: Argument is rejected by its parameter's validation attribute

**Severity:** Error

The value passed to a validated parameter is known at compile time, and one of the parameter's
validation attributes rejects it. Wherever Stipulate enforces the attribute at run time, the call
can only throw, so the analyzer reports it now instead.

```csharp
public static class Scale
{
    public static void Set([Range(1, 10)] int level) { }
}

public static class Caller
{
    public const int Off = 0;

    public static void Call()
    {
        // error ST3001: The argument Off (0) for parameter 'level' of 'Scale.Set(int)' is
        // rejected by [Range(1, 10)], which requires Value >= 1, but Value is 0. Wherever
        // Stipulate enforces the attribute at run time, this call throws ArgumentException.
        // Pass a value [Range(1, 10)] accepts, or, if the value is right, correct the attribute.
        // If the call is meant to throw, as in a test of the check, suppress ST3001 there.
        Scale.Set(Off);
    }
}
```

The message says which value, which parameter, which attribute and why, what the call will
throw, and how to fix it.

## What is checked

| The value passed | Example |
|---|---|
| A literal, a `const`, or an expression of them | `Set(0)`, `Set(Off)`, `Set(Off - 1)` |
| `null` | `Rename(null)` against `[Required]` |
| An array or collection written where it is passed | `Multiply([])`, `Multiply(new int[0])`, `Multiply(new[] { 1, 2 })`, as arrays or a `List<T>` |
| The arguments of a `params` parameter | `Sum()` against `[MinLength(1)] params int[] values` |
| A parameter's default value | `void Set([Range(1, 10)] int level = 0)` |

A call that leaves an argument out isn't reported: its default value is, once, where it is
declared.

```csharp
public static class Multiplier
{
    public static int[] Multiply([MinLength(1)] int[] array) => array;
}

public static class Scale
{
    // error ST3001: the default value 0 is rejected by [Range(1, 10)]
    public static void Set([Range(1, 10)] int level = 0) { }
}

public static class Caller
{
    public static void Call()
    {
        // error ST3001: the argument [] is rejected by [MinLength(1)]: Length is 0
        Multiplier.Multiply([]);
        Scale.Set();
    }
}
```

The attributes checked are the ones the analyzer can describe: the built-in `[Required]`,
`[MinLength]`, `[MaxLength]`, `[Length]`, `[StringLength]`, `[Range]`, `[AllowedValues]` and
`[DeniedValues]`, and any attribute [described with `[ComparableValidation]`](../use/custom-attributes.md).
A call through an interface or a base class is checked against that method's attributes, as
its caller sees them.

## What isn't

Only a value certain to be rejected is reported. Anything the analyzer can't be sure of is left to
run-time enforcement:

- a value computed at run time: a variable, a method's result, a `static readonly` field;
- an attribute that isn't described;
- a collection whose number of elements isn't the number written: one with a spread
  (`[.. others]`), or of a type such as a set, which can merge elements;
- a fraction against a whole-number `[Range]`: `Range(int, int)` rounds the value to an `int`
  before comparing it, so `0.6` passes `[Range(1, 10)]`;
- a `[Range]` whose bounds are given as text, such as `Range(typeof(DateTime), "2020-01-01", ...)`;
- a value converted by a user-defined conversion: what reaches the attribute is the conversion's
  result.

`[AllowedValues]` and `[DeniedValues]` compare values as they do at run time, with `Equals` once
both are boxed: so `[AllowedValues(1, 2)]` on a `long` parameter rejects `1L`, because a boxed
`long` is never equal to a boxed `int`.

## How to fix it

Pass a value the attribute accepts. If the value is right, the attribute is wrong: correct it, so
that it states what the method really accepts.

```csharp
public static class Scale
{
    public static void Set([Range(0, 10)] int level) { }
}

public static class Caller
{
    public const int Off = 0;

    public static void Call() => Scale.Set(Off);
}
```

A call that is meant to throw, as in a test that checks the attribute is enforced, is the
exception: suppress ST3001 for it, where it is.

```csharp
public static class Scale
{
    public static void Set([Range(1, 10)] int level) { }
}

public static class ScaleTest
{
    public static bool Set_WhenTheLevelIsZero_Throws()
    {
        try
        {
#pragma warning disable ST3001 // The call is meant to throw.
            Scale.Set(0);
#pragma warning restore ST3001
            return false;
        }
        catch (System.ArgumentException)
        {
            return true;
        }
    }
}
```

The check doesn't depend on `StipulateMode`: with `None`, the call doesn't throw, but it still
passes a value the method says it doesn't accept.
