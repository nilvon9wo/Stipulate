# PV2003: Invalid [ComparableValidation]

**Severity:** Error

A `[ComparableValidation]` description the analyzer can't use. The attribute it describes is
treated as undescribed, so it can only be compared with identical usages of itself.

```csharp
// error PV2003: This [ComparableValidation] is invalid because a LowerBound needs an Argument
// or a Value
[ComparableValidation(ValidationDimensions.Length, ValidationComparison.LowerBound)]
public sealed class NotEmptyAttribute : ValidationAttribute { }
```

The message says what is wrong:

| Because | Meaning |
|---|---|
| the dimension is empty | Name a dimension, ideally one of `ValidationDimensions`. |
| ... isn't a ValidationComparison | The comparison is a number cast to the enum, outside it. |
| ... isn't a ValidationAttribute | The described class doesn't derive from `ValidationAttribute`. |
| a Flag takes no Argument, Value, IsExclusive or ExclusiveArgument | A flag has no bound. |
| a ... needs an Argument or a Value | A bound or a list of values must come from somewhere. |
| ... has no constructor parameter or settable property named ... | `Argument` names no member of the attribute. |
| the Value of a ... must be a number / an array | A bound is a number; a list of values is an array. |
| only a LowerBound or an UpperBound can be exclusive | `IsExclusive` or `ExclusiveArgument` on something that isn't a bound. |
| ... has no bool constructor parameter or settable property named ... | `ExclusiveArgument` names no `bool` member of the attribute. |
| on an assembly it needs the type of the attribute it describes | On an assembly, use the form that takes `typeof(...)`. |
| on a class it describes that class, so it takes no attribute type | On a class, use the form without `typeof(...)`. |

## How to fix it

Say where the bound comes from:

```csharp
[ComparableValidation(ValidationDimensions.Length, ValidationComparison.LowerBound, Value = 1)]
public sealed class NotEmptyAttribute : ValidationAttribute { }
```

See [custom validation attributes](../use/custom-attributes.md).
