# Contributing to ParameterValidation

You are here to work on ParameterValidation itself: the weaver, the generator, the analyzer and
its code fix, the contracts, their tests and documentation.

| Page | Covers |
|------|--------|
| [coding-standards](coding-standards.md) | The rules the code is held to: the review checklist. Read this first. |
| [local-development](local-development.md) | Building, testing and running every gate locally; WSL and Smart App Control. |
| [test-suites](test-suites.md) | The test projects, what each one proves, and the documentation examples. |
| [coverage-standards](coverage-standards.md) | 100% line and branch coverage on every test run, and what to do when it's hard to reach. |
| [ci](ci.md) | What the GitHub Actions workflow runs, and how `verify-gates.py` proves each gate still fires. |

The standards are those of
[ExtremeCSharpTestDataFactory](https://github.com/nilvon9wo/ExtremeCSharpTestDataFactory) (XFTY),
adopted wholesale; where this repository differs, these pages say so.
